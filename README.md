# haizarakun

**[PayPaySoundHook](https://github.com/haizarakun/PayPaySoundHook)**
An LSPosed module that replaces PayPay's payment-complete and chat sounds with your own audio files.

**[chrome-update-notifier](https://github.com/haizarakun/chrome-update-notifier)**
A lightweight Chrome extension that predicts the 4-week release cycle and notifies you of Chrome updates.
